    How Lineup Setup works

    It reads your contests

    From your DraftKings entries file it sorts each contest into cash, small, medium or massive tournament, using the contest name, entry fee and prize pool, and suggests an approach for each.

    It uses your lineups first

    Lineups you built in the Optimizer on this device are used first. If you have none, or not enough for a big contest, it builds the rest with the same optimizer.

    It fills and checks the slate

    One best cash lineup goes in every cash entry. Tournament lineups are spread across the rest with no repeats inside a contest. Every export is checked and read back before download.
